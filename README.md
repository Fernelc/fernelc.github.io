# Fernel Campher — Executive Portfolio

A GitHub Pages-ready, mobile-responsive static website. No build tools or hosting fees required.

## Before publishing (important)
- Replace `assets/portrait-placeholder.svg` with the **approved** professional portrait, preferably saved as `assets/fernel-headshot.jpg`, then in `index.html` change `src="assets/portrait-placeholder.svg"` to `src="assets/fernel-headshot.jpg"`.
- Replace `ADD-YOUR-EMAIL@example.com` with a suitable **public professional** email address.
- Replace `https://www.linkedin.com/` with the correct LinkedIn profile URL.
- Confirm all role names, appointment dates, NQF level, institution, qualifications and descriptions before publishing. Do not publish unsupported achievements or confidential records.
- Upload an approved CV as `assets/Fernel-Campher-CV.pdf`, change the download link as described in `assets/CV-INSTRUCTIONS.txt`.
- The programme portfolio currently contains thematic placeholders, not verified individual project case studies. Add project names, dates, outcomes, partners and supporting links after validating sources.
- This site is **independent**, not an official website or endorsement by the South African Red Cross Society or any other institution.

## Publish free with GitHub Pages
1. Create or sign into a GitHub account at https://github.com/
2. Click the **+** menu then **New repository**. Name it `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your exact GitHub username. Set **Public** (required for free Pages).
3. Create the repository and upload `index.html`, `assets/` and `.nojekyll` to the **root** of the repository using **Add file → Upload files → Commit changes**. **Do not upload the outer `fernel-executive-portfolio` folder** — `index.html` must be at the repository root.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Choose `main` and `/(root)`, then **Save**.
5. Open `https://YOUR-USERNAME.github.io/` after the deployment finishes. It can take several minutes.

### Editing later
Open a file on GitHub, click the pencil icon, edit, and commit. For photos/PDFs, use **Add file → Upload files**. Changes republish after deployment.

### Local preview
Double-click `index.html` in your browser. All assets are local except the web font (which falls back to system fonts offline).

### Privacy, security and branding
Everything in this public repository is visible to visitors, including uploaded files. Do not upload disciplinary records, private contact details, internal donor documents, identification numbers or confidential financial records. Only use logos and project photos where permitted. Website contact email is visible to spam crawlers; consider a dedicated professional address.
